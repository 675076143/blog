# 独立双系统物理隔离安装方案

> 2026-07-26

## 问题

装双系统你肯定遇到过：Windows 装完，Linux 起不来了。或者反过来。

原因很简单——Windows 安装器会扫描所有磁盘，把引导写入第一个可用的 EFI 分区，**不一定是你要装的那块盘**。

## 方案：拔盘

最可靠的方法就是物理隔离：装系统时把另一块硬盘拔掉，让两个系统完全不知道对方的存在。

### 1. 准备阶段（Linux 下）

```bash
# 清理 Windows 盘相关的 BIOS 启动项
sudo efibootmgr -B -b 0000
```

### 2. 安装 Windows

1. **关机**，拔掉 Linux 盘
2. 插入 Windows 安装 U 盘，正常安装
3. Windows 会自动在自己的盘上创建 EFI 分区，互不干扰

### 3. 恢复双系统

1. **关机**，插回 Linux 盘
2. 进 BIOS，把 Linux 的引导设为第一启动项，Windows 设为第二
3. 以后按 F12 选盘启动

## 效果

- **物理隔离**：拔掉任一硬盘，另一块都能独立启动
- **更新不互伤**：Windows 更新不会破坏 Linux 引导
- **简单可靠**：无需配置 GRUB/os-prober

BIOS 启动项类似这样：

```
Boot0000* Windows Boot Manager  → 硬盘 A
Boot0001* Limine               → 硬盘 B
```

## 适合谁

- 台式机用户（方便插拔 M.2/SATA）
- 笔记本不推荐（拆机麻烦），可以用 diskpart 手动分区替代

这个方法听起来粗暴，但确实是处理双系统引导问题最省心的方案。
